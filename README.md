# Nusantara Global Export — Company Profile Website

Static company-profile website for **Nusantara Global Export**, an Indonesian
exporter of coconut products: semi-husked coconut, mature coconut, copra,
shell charcoal, coco peat, and coco fiber.

## Pages

- `index.html` — homepage with hero slideshow
- `products.html` — product catalog
- `about.html` — company profile
- `contact.html` — contact / inquiry (via WhatsApp)

## Stack

Plain HTML + CSS + vanilla JS, no build step. Open `index.html` in a browser
or serve the folder with any static server:

```sh
npx serve .
```

## Structure

```text
assets/   # favicon, hero images
css/      # styles
js/       # hero slideshow, language switcher, main script
docs/     # agent/domain docs
```
